## Status

- **Protocol**: DOOM / Latveria Protocol — ACTIVE
- **Target date**: 2026-12-18T00:00:00
- **Theme**: Metallic Latverian green HUD, boot sequence, critical mode (final 24h), arrival mode

## What this is

Doctor Doom Countdown is a pure front-end experience built with only HTML, CSS and JavaScript.

No frameworks. No libraries. No build step. Just Doom.

Features:
- Cinematic Doctor Doom inspired UI
- Metallic + Latverian green aesthetic
- Real-time countdown (days / hours / minutes / seconds)
- Fully responsive
- Boot sequence, side system panels, threat level, rotating system messages
- Critical mode when fewer than 24 hours remain
- Arrival celebration when the countdown reaches zero
